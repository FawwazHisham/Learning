# RPA Python Automation — Complete Course

```
┌──────────────────────────────────────────────────────────────────┐
│           ROBOTIC PROCESS AUTOMATION WITH PYTHON                 │
│                                                                  │
│   Selenium ──► Web Automation      (browser control)            │
```
